# ฉาด! เอาตัวรอดจากแก๊งจอมแกล้ง ✋

เกมเอาตัวรอดแนว Survivor.io / Vampire Survivors เล่นบนเบราว์เซอร์ได้ทั้งคอมพิวเตอร์และมือถือ
ตัวละครตบอัตโนมัติ ผู้เล่นมีหน้าที่เดินหลบ เก็บดาวเพื่อเลเวลอัป และวิวัฒน์ท่าตบ

## วิธีเล่น
- คอมพิวเตอร์: `W A S D` หรือปุ่มลูกศรเพื่อเดิน, `1 2 3` เลือกการ์ด, `R` สุ่มการ์ดใหม่, `Esc` หยุดเกม
- มือถือ: แตะค้างตรงไหนก็ได้แล้วลากเพื่อเดิน

## เปิดเล่นด้วย GitHub Pages
1. สร้าง repository ใหม่ (ตั้งเป็น Public)
2. อัปโหลดไฟล์ `index.html`, `README.md` และ `.nojekyll` ไว้ที่โฟลเดอร์บนสุดของ repo
3. ไปที่ **Settings → Pages**
4. ที่ **Source** เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด **Save**
5. รอประมาณ 1–2 นาที เกมจะเล่นได้ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## รายละเอียดทางเทคนิค
- เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้อง build ไม่มี dependency (ใช้ Google Fonts เท่านั้น ถ้าโหลดไม่ได้จะใช้ฟอนต์ของระบบแทน)
- ความคืบหน้า (เหรียญ อัปเกรด สถิติ) บันทึกใน `localStorage` ของเบราว์เซอร์ผู้เล่นแต่ละคน
- ตัวละครและภาพทั้งหมดวาดด้วยโค้ด ไม่ใช้ asset ที่มีลิขสิทธิ์ของผู้อื่น
